# SOC 2 Access Control Case Study

## Situation
A SaaS organization lacks formalized access control processes, increasing the risk of unauthorized access to sensitive customer data.

## Task
Design and evaluate access control mechanisms aligned with SOC 2 (CC6), ISO 27001 (A.9), and NIST 800-53 (AC).

## Action

### Risk Identified
- Unauthorized access due to lack of MFA
- Inconsistent user provisioning/deprovisioning

### Control Implementation
- Enforced multi-factor authentication (MFA)
- Established quarterly access reviews
- Defined user provisioning procedures

### Audit Approach
- Reviewed access control policy
- Validated user access lists
- Verified evidence of quarterly reviews
- Sampled users for appropriate access

### Stakeholder Coordination
- Engineering: MFA implementation
- IT: Access provisioning controls
- Management: Access approval

## Result
- Reduced likelihood of unauthorized access
- Improved audit readiness
- Established repeatable access control process

## Key Takeaway
Effective access control requires not only implementation of technical safeguards, but also consistent governance, monitoring, and cross-team coordination.
