# GRC Workflow Simulation (Ticket-Based)

## Objective
Simulate how GRC processes are managed using ticketing systems such as ServiceNow or Jira.

## Example Workflow: Access Request

1. User submits access request ticket  
2. Manager reviews and approves  
3. IT provisions access  
4. GRC validates control and logs activity  
5. Access is included in quarterly access reviews  

## Control Alignment
- SOC 2: CC6 (Logical Access)  
- ISO 27001: A.9 (Access Control)  
- NIST 800-53: AC (Access Control)  

## Value

This workflow demonstrates how GRC processes are operationalized within real-world tools, ensuring:

- Traceability of access decisions  
- Accountability across stakeholders  
- Audit readiness through documented evidence
