# Risk Management Project

This project demonstrates a structured approach to identifying, assessing, and managing cybersecurity risks.

## Methodology
- Likelihood (1–5)
- Impact (1–5)
- Risk Score = Likelihood × Impact

## Framework Alignment
- ISO 27001: Clause 6
- SOC 2: CC3
- NIST CSF: ID.RA

## Sample Risks
- Unauthorized access
- Lack of MFA
- Insufficient logging
