# Control Mapping Matrix

This project demonstrates how a single security control can satisfy multiple compliance frameworks.

## Example Mapping

### Access Control

- ISO 27001: A.9
- SOC 2: CC6
- NIST 800-53: AC

## Explanation
Although each framework uses different terminology, they all require:
- Restricting access to authorized users
- Enforcing least privilege
- Periodic access reviews

## Value
This mapping helps organizations reduce duplicate work by aligning controls across frameworks.
