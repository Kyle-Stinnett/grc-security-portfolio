# GRC Security Portfolio

This repository demonstrates practical Governance, Risk, and Compliance (GRC) capabilities aligned with ISO 27001, SOC 2, and NIST Cybersecurity Framework (CSF).

## Overview
This portfolio includes hands-on examples of:
- Risk identification and assessment
- Control mapping across multiple frameworks
- Audit support and evidence preparation
- Security program documentation (ISMS)

## Frameworks Covered
- ISO 27001
- SOC 2
- NIST CSF
- NIST 800-53

## Projects
- Risk Management Project
- Control Mapping Matrix
- SOC 2 Audit Simulation
- ISO 27001 ISMS
- NIST CSF Implementation
